# 3D

#### 释放资源

```ts
renderer.dispose();
renderer.forceContextLoss()
```

`renderer.dispose();`的含义是：清理 renderer 内部缓存的 WebGL 资源。

`renderer.forceContextLoss()`它的意思是：强制让当前 WebGL 上下文失效

生产项目里不一定每次都要用 **forceContextLoss**，尤其是复杂项目、多个 canvas、或者有复用 renderer 的架构时，需要谨慎。

#### canvas动画失效

**DOM 里有多个 canvas，导致你看到的 canvas 不一定是正在被 Three.js 动画更新的那个。**

我们通过：

```
container.innerHTML = '';
```

清掉旧 canvas；





#### 添加物体的阴影(四者缺一不可)

`MeshStandardMaterial` 需要灯光
 `AmbientLight` 负责整体亮度
 `DirectionalLight` 负责方向感和阴影
 `castShadow` 表示“我投射阴影”
 `receiveShadow` 表示“我接收阴影”

+ renderer 开启阴影

```
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
```

+ 让平行光可以产生阴影

```ts
directionalLight.castShadow = true;
```

```ts
const directionalLight = new THREE.DirectionalLight('#ffffff', 2);
directionalLight.position.set(3, 3, 5);
directionalLight.castShadow = true;
scene.add(directionalLight);
```

+ 让物体可以产生阴影

```
cube.castShadow = true;
```

+ 让地面可以接收阴影

```
floor.receiveShadow = true;
```

**释放资源**

```
directionalLight.shadow.map?.dispose();
```





#### 窗口变化 Three.js 自动适配。

```ts
function handleResize() {
  const width = container.clientWidth;
  const height = container.clientHeight;

  camera.aspect = width / height;
  camera.updateProjectionMatrix();

  renderer.setSize(width, height);
}

window.addEventListener('resize', handleResize);
```

记得要移除释放资源

```
window.removeEventListener('resize', handleResize);
```

#### 在不同设备下面，都能做到相同速度的动画：

```ts
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

type AnimationLoopParams = {
  scene: THREE.Scene;
  camera: THREE.PerspectiveCamera;
  renderer: THREE.WebGLRenderer;
  controls: OrbitControls;
  cubeGroup: THREE.Group;
};

export function startAnimationLoop({
  scene,
  camera,
  renderer,
  controls,
  cubeGroup,
}: AnimationLoopParams) {
  let animationId = 0;

  const timer = new THREE.Timer();

  const rotationSpeed = 1.8;

  function animate() {
    animationId = requestAnimationFrame(animate);

    timer.update();

    const deltaTime = timer.getDelta();

    cubeGroup.rotation.y += rotationSpeed * deltaTime;

    controls.update();
    renderer.render(scene, camera);
  }

  animate();

  const stop = () => {
    cancelAnimationFrame(animationId);
  };

  return {
    stop,
  };
}
```

timer.update();  是告诉计时器：现在进入新的一帧了，刷新本帧时间。

timer.getDelta();是拿到：上一帧到这一帧经过了多少秒。

cubeGroup.rotation.y += rotationSpeed * deltaTime; 就是：按照真实经过的时间来旋转，而不是按照帧数旋转。
